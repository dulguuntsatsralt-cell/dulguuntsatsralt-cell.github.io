Research

  • Mk33 – A fully specified recipe and reference implementation for training long-horizon self-improving agents. Sole author, preprint, 2026. Read the paper
  • Mk33 Bench – Four small CPU-only environments for measuring whether an agent keeps improving over many rounds, on a laptop with any API or local model

Mk33

  • AREX-2 (BAAI) showed that an agent trained on long improvement runs keeps getting better with more rounds, but described its training recipe only in prose. Mk33 makes every step code, every threshold a config value, and every design choice an ablation
  • Environment checks – A common score scale, a noise-aware headroom filter, benchmark decontamination, and an isolated scorer
  • Round ledger compaction – A one-line record of every round replaces old turns once a multi-hour run fills the context window
  • Progress-aware loss masking – No training signal for repeated, empty or polling turns; full weight for turns that improved the score
  • Matched contexts – One context builder for the agent and the training data
  • Open source – Version 0.1.0 under Apache-2.0, with 43 tests that GitHub Actions runs on every change
